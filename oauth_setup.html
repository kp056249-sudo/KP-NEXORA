GOOGLE OAUTH SETUP

Fix Google access

If Google shows “Access blocked”, the Google Cloud OAuth audience is blocking the account. The app cannot bypass Google's authorization rules.

1. Add your Google account as a Test user

Open Google Cloud Console → Google Auth Platform → Audience → Test users → Add users. Add the exact Gmail/Google Workspace account you are using to sign in or connect Sheets.

Important: Keep the OAuth app in Testing while you are developing. Google documents that testing apps are limited to accounts listed as test users.

Open Google OAuth Audience

2. Authorized redirect URIs

In the same Web application OAuth client, put these under Authorized redirect URIs:

{{ login_callback }}
{{ sheets_callback }}

Do not put these in Authorized JavaScript origins for this server-side local setup.
