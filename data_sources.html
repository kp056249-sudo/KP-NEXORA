Google Sheets

Public + Secure OAuth

Public import uses Google’s published-to-web CSV endpoint and does not need OAuth. Private sheets use your connected Google account.

Connect Google Account
⚠ If Google says “Access blocked”

If Google says Access blocked, add the EXACT Google account you are using under Google Cloud → Google Auth Platform → Audience → Test users. Also make sure the Sheets API is enabled and the Web OAuth client contains the exact callback shown in the setup guide. This is controlled by Google Cloud, so the app cannot bypass a blocked account.

Open Google setup guide
