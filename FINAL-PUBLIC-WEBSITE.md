## Important: ZIP vs public internet
A ZIP is the complete website source, but a ZIP cannot by itself make the website available when someone searches from another phone.

For the website to open from any phone, it must be deployed to a public HTTPS URL. After deployment, set:

`KP_NEXORA_SITE_URL=https://YOUR-FINAL-DOMAIN`

Then use the public URL on any phone. Search-engine discovery/indexing is separate from hosting and can take time; a sitemap and Search Console submission can help, but no software can guarantee an immediate top search result.

## Production secrets
Set these as hosting environment variables and never commit them:
- `FLASK_SECRET_KEY`
- `DATABASE_URL`
- `GROQ_API_KEY`
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `KP_NEXORA_SITE_URL`

For production Google OAuth, use HTTPS callback URLs generated by the deployed app and add those exact URLs in the Google Cloud OAuth client.

## Local PostgreSQL note
Installing PostgreSQL does not automatically migrate the existing local SQLite database. The PostgreSQL connector and the application's PostgreSQL database mode are separate settings. Set `DATABASE_URL` only when you intentionally want KP NEXORA's own application database to use PostgreSQL.
